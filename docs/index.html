How to add or update your dataset's metadata

If your dataset card shows a ⚠ Needs info badge, the scanner couldn't auto-detect some fields. Fill them in with a simple YAML file.

Step 1 — Create dataset_info.yaml in your dataset folder

Copy the template below into your dataset folder on the HPC:

cp /home/woody/iwi5/iwi5145h/Databases/dataset-registry/templates/dataset_info.yaml \
    /home/janus/iwi5-datasets/YOUR_DATASET_NAME/dataset_info.yaml

Step 2 — Fill in the fields

nano /home/janus/iwi5-datasets/YOUR_DATASET_NAME/dataset_info.yaml

Replace every ??? with the correct value. Example:

name: MIMIC-CXR
description: Chest X-ray dataset with radiology reports from BIDMC.
modality: 2D
domain: medical_imaging
tasks:
  - classification
  - report_generation
annotations:
  - radiology_reports
  - class_labels
classes: null
num_samples: 227827
preprocessing: DICOM converted to de-identified PNG
citation: |
  Johnson et al. MIMIC-CXR-JPG, a large publicly available database
  of labeled chest radiographs. arXiv:1901.07042
is_public: false
license: PhysioNet Credentialed

Step 3 — Ask the registry owner to rescan

Once your file is saved, ask sheethal.bhat@gmail.com to run:

bash /home/woody/iwi5/iwi5145h/Databases/dataset-registry/sync.sh

Your dataset card will update on this dashboard within a few minutes.
